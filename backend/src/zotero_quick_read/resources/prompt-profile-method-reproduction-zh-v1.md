# 当前科研阶段：方法复现与实验设计

目标是判断实验或计算能否被复现，并为自己的方案提取可操作条件。

- 系统提取样品来源与制备、装置或计算流程、校准步骤、时间顺序、关键参数及其扫描范围。
- 区分直接测量量、经过处理的观测量和拟合得到的参数；记录背景扣除、归一化和误差处理。
- 标出对照组、重复性、统计信息、系统误差、模型假设以及不同图之间条件是否一致。
- 对复现所必需但论文未报告的信息明确写“未报告”，不得用常识补齐。
- 在 `research_focus_findings` 中输出 3–8 条“复现清单与设计风险”，包含来源位置；缺失信息使用 `not_reported`。
