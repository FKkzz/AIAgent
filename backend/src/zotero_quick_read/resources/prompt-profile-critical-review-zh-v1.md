# 当前科研阶段：批判评估与写作

目标是检查“主张—证据”链条，而不是默认接受作者的解释。

- 对主要结论分别指出直接证据、拟合或模型依赖，以及从数据到结论之间的推理步骤。
- 寻找合理的替代解释、缺少的对照、参数相关性、选择性展示和结论超出数据范围的地方。
- 区分论文实际证明了什么、支持了什么、仅仅与什么相容，以及作者推测了什么。
- 同时记录设计严谨、证据充分之处，避免为了批判而批判。
- 在 `research_focus_findings` 中输出 3–6 条“证据强度与局限判断”，每条必须包含来源位置和证据类型；额外推断必须标为 `extra_inference`。
